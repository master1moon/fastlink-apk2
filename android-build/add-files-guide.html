🎯 الطريقة 1: سكريبت تلقائي (الأسهل)

📥 حمّل السكريبت وشغّله

هذا السكريبت يقوم بكل شيء تلقائياً:

  • ✅ تحميل ملفات التطبيق الأصلي من song10
  • ✅ نسخها إلى مجلد www/
  • ✅ تطبيق جميع التعديلات المطلوبة
  • ✅ تثبيت التبعيات
  • ✅ إضافة منصة Android
  • ✅ مزامنة Capacitor
⬇️ تنزيل سكريبت Linux/Mac ⬇️ تنزيل سكريبت Windows
# على Linux/Mac:
chmod +x setup-complete.sh
./setup-complete.sh

# على Windows:
setup-complete.bat

🔧 الطريقة 2: يدوياً (خطوة بخطوة)

الخطوة 1: استنساخ المستودع

git clone https://github.com/master1moon/fastlink-apk2.git
cd fastlink-apk2/android-build

الخطوة 2: تحميل التطبيق الأصلي

git clone https://github.com/master1moon/song10.git temp

الخطوة 3: نسخ الملفات إلى www/

# إنشاء مجلد www
mkdir -p www

# نسخ ملفات التطبيق
cp temp/index.html www/
cp temp/app.js www/
cp temp/manifest.json www/
cp temp/serviceworker.js www/
cp -r temp/css www/
cp -r temp/fonts www/
cp -r temp/icons www/
cp -r temp/js www/

# حذف المجلد المؤقت
rm -rf temp

الخطوة 4: تطبيق التعديلات

4.1 تعديل index.html

افتح www/index.html واستبدل CSP بـ:

<meta http-equiv="Content-Security-Policy"
  content="default-src 'self' https: blob:;
           script-src 'self' 'unsafe-inline' 'unsafe-eval' https:;
           style-src 'self' 'unsafe-inline' https:;
           img-src 'self' https: blob:;
           font-src 'self' https:;
           connect-src 'self' https: blob:;">

أضف قبل </body>:

<script src="capacitor-bridge.js"></script>

4.2 تعديل serviceworker.js

افتح www/serviceworker.js وأضف في البداية:

const isCapacitor = typeof window !== 'undefined' && typeof window.Capacitor !== 'undefined';
if (request.url.startsWith('capacitor://')) return;

4.3 تعديل app.js

افتح www/app.js وأضف في DOMContentLoaded:

if (typeof window.Capacitor !== 'undefined') {
  console.log('يعمل داخل تطبيق أندرويد');
  if (window.Capacitor.Plugins && window.Capacitor.Plugins.SplashScreen) {
    window.Capacitor.Plugins.SplashScreen.hide();
  }
}

الخطوة 5: تثبيت التبعيات والبناء

# تثبيت التبعيات
npm install

# إضافة منصة Android
npx cap add android

# مزامنة Capacitor
npx cap copy
npx cap sync android

# فتح Android Studio
npx cap open android
