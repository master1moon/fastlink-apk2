🎯 ما هو GitHub Actions؟

GitHub Actions هي خدمة مجانية من GitHub تسمح لك بتشغيل أوامر بناء تلقائياً على خوادم GitHub القوية.

مجاني 100% لا يحتاج جهاز قوي خوادم GitHub تتكفل بكل شيء تلقائي بالكامل APK جاهز للتحميل

📋 الخطوات (5 دقائق فقط)

1

افتح المستودع على GitHub

اذهب إلى مستودع المشروع:

🔗 فتح المستودع
2

فعّل GitHub Actions

في المستودع:

  1. اضغط على تبويب Actions في الأعلى
  2. اضغط على زر Enable Actions أو I understand my workflows, go ahead
  3. ستظهر لك workflow باسم Build APK
3

شغّل البناء

لبدء بناء APK:

  1. اضغط على Build APK
  2. اضغط على Run workflow (زر أخضر على اليسار)
  3. اضغط على Run workflow مرة أخرى للتأكيد

💡 ملاحظة: إذا لم تجد زر Run workflow، قم بعمل commit لأي ملف أولاً

4

انتظر 5-10 دقائق

GitHub سيقوم تلقائياً بـ:

  • ✅ تحميل ملفات التطبيق الأصلي
  • ✅ تطبيق جميع التعديلات
  • ✅ تثبيت التبعيات
  • ✅ بناء مشروع Android
  • ✅ إنشاء ملف APK

⏱️ الوقت المتوقع: 5-10 دقائق

5

حمّل ملف APK

بعد اكتمال البناء:

  1. اضغط على Build (أحدث تشغيل)
  2. في الأسفل، ستجد Artifacts
  3. اضغط على fastlink-accounts-apk للتحميل

🎉 تهانينا!

ستحصل على ملف APK جاهز للتثبيت على أي جهاز أندرويد!

💡 نصائح مهمة

🎯 للحصول على أفضل نتيجة:

  • استخدم فرع main: سيتم إنشاء Release تلقائياً
  • انتظر حتى ينتهي: لا توقف العملية أثناء البناء
  • تحقق من الحجم: APK النهائي ~8-12 MB
  • اختبر على جهاز: قبل النشر على Google Play

⚠️ حدود GitHub Actions المجاني

• 2000 دقيقة شهرياً للمستودعات العامة (أكثر من كافٍ)
• 500 MB تخزين للملفات المبنية
• لا يوجد حد لعدد مرات البناء
• مجاني 100% للمستودعات العامة

🐛 استكشاف الأخطاء

❌ فشل البناء

إذا فشل البناء، تحقق من:

  • اضغط على Build الفاشل
  • اضغط على الخطوة الفاشلة لرؤية الأخطاء
  • تحقق من logs لمعرفة السبب
  • أعد المحاولة بعد إصلاح المشكلة

❌ لم أجد زر Run workflow

هذا يعني أنك تحتاج لعمل commit أولاً. قم بتعديل أي ملف (مثل README.md) وادفع التغييرات، ثم ستظهر لك الخيارات.
