# 🚀 دليل سريع لبناء APK

## ⚡ الطريقة الأسرع (5 دقائق)

### المتطلبات:
- Node.js 18+ ([تحميل](https://nodejs.org))
- Android Studio ([تحميل](https://developer.android.com/studio))

### الخطوات:

```bash
# 1. انسخ جميع ملفات التطبيق الأصلي إلى مجلد www/
# من مستودع: https://github.com/master1moon/song10

# 2. شغّل سكريبت البناء
chmod +x build-android.sh
./build-android.sh

# 3. ستحصل على: fastlink-accounts.apk
```

### الطريقة البديلة (Windows):

```cmd
build-android.bat
```
